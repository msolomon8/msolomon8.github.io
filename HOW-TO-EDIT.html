How to edit your portfolio

Everything on the site (text, photos, videos, links) lives in one block of text near the bottom of index.html. You never have to touch the layout code. This guide takes about 10 minutes the first time.

Jump to: 1 · Set up · 2 · Change text · 3 · Add photos · 4 · Add videos · 5 · Add a project · 6 · Headshot, résumé, colors · 7 · Put it online · 8 · If something breaks

1 · Set up (once)

  1. Unzip mia-portfolio.zip somewhere you'll keep it, e.g. Documents/GitHub/mia-portfolio.
  2. Open the folder in VS Code (File → Open Folder…). You'll see: 
    mia-portfolio/
├── index.html        ← the website (you edit the SITE block)
├── HOW-TO-EDIT.html  ← this guide
├── images/           ← put photos here
└── videos/           ← put short video files here
  3. To preview, double-click index.html so it opens in Chrome/Safari. After every edit: save (⌘S) in VS Code, then refresh (⌘R) in the browser.
Nice-to-have: install the VS Code extension Live Server, right-click index.html → Open with Live Server. The page then refreshes by itself every time you save.

2 · Change any text

In index.html, press ⌘F and search EDIT ME. Everything between that and END OF EDIT ME is your content. It looks like this:

tagline: "Mechanical engineering student and varsity swimmer at Tufts...",

Just change the words between the quotes. Three rules keep it from breaking:

  • Text stays inside "double quotes". If you need a quote mark inside the text, use a curly one (’ or “ ”).
  • Every line/item in a list ends with a comma.
  • Brackets come in pairs: [ ] for lists, { } for one project or job.

Anywhere you see ✏️ is a placeholder I left for you to fill in (Meyers+ dates and title, the Materials & Manufacturing and Engineering Design project write-ups, LinkedIn URL, and your “What I love” list). I couldn't open your Notion sub-pages, so copy those descriptions over from Notion.

Long project descriptions are a list of paragraphs. Each "..." becomes its own paragraph in the pop-up:

description: [
  "First paragraph about the project.",
  "Second paragraph with results.",
],

3 · Add photos to a project

  1. Copy your photo files into the images folder. Use simple names with no spaces, like pingpong-setup.jpg.
  2. Find the project in the SITE block and add each photo to its media list: 
    media: [
  "images/pingpong-setup.jpg | Full setup with the LEGO paddle",
  "images/pingpong-cad.png | CAD of the paddle mount",
],
  3. Save and refresh. The first photo becomes the picture on the project card; clicking the card opens a gallery with all of them.
  • The part after | is an optional caption. Leave it out if you don't want one: "images/pingpong-setup.jpg",
  • Want a different card picture than the first gallery photo? Add cover: "images/whatever.jpg", inside that project's { }.
  • File names are case-sensitive once online: IMG_1234.JPG ≠ img_1234.jpg.
  • Keep photos under ~1–2 MB so the site loads fast. On a Mac: open in Preview → Tools → Adjust Size → width 1600 → Save. iPhone HEIC photos won't show in all browsers; export them as JPG first.
Shortcut: open index.html#tools in your browser (add #tools to the end of the address and refresh). Pick your photos/videos there and it writes the lines for you to copy-paste into media: [ ].

4 · Add videos

Videos go in the same media list as photos. Cards with a video automatically get a “▶ video” label. You have three options:

OptionWhat to writeBest for
YouTube (recommended)"https://youtu.be/abc123XYZ | Demo run",Anything longer than ~20 s. Upload as Unlisted if you don't want it searchable.
Google Drive"https://drive.google.com/file/d/FILE_ID/view | Demo",Quick option. Set sharing to “Anyone with the link”.
Video file"videos/arm-demo.mp4 | Arm tracking",Short clips (under ~25 MB). Put the file in videos/.

Vimeo links work too. Mix freely:

media: [
  "images/arm-photo.jpg | Final arm",
  "https://youtu.be/abc123XYZ | Digital twin following the arm",
  "videos/arm-closeup.mp4 | Encoder knobs",
],
Why YouTube for long videos: GitHub (step 7) rejects files over 100 MB, and big video files make your site slow. iPhone .mov files are often huge, so trim them or upload to YouTube instead.

5 · Add (or remove) a project

Each project is one { ... }, block in the projects: [ ] list. Easiest way: copy a whole existing block (from its { to its },), paste it right after, and change the words.

{
  title: "Project name",
  category: "Mechatronics",          // must match one of the categories list exactly
  course: "ME 35 · Intro to Robotics",
  summary: "One or two sentences for the card.",
  description: [ "Paragraph 1.", "Paragraph 2." ],
  skills: ["SolidWorks", "Arduino"],
  media: [ "images/photo1.jpg | caption" ],
  links: [ { label: "Code on GitHub", url: "https://github.com/..." } ],
},
  • Order on the page = order in the list. Cut and paste blocks to reorder.
  • Remove a project: delete its whole block, including the trailing },.
  • Filter buttons come from categories: [ ... ]. Add/rename them there, and make sure each project's category matches one exactly (spelling and capitals).
  • The “Projects” number at the top counts automatically.
  • Experience works the same way: copy a { dates, role, company, text, bullets } block. Put bullet points in bullets: ["Did X", "Did Y"] or leave it as [].

6 · Headshot, résumé, colors

Headshot

Put the photo in images/, then set photo: "images/headshot.jpg",. If your face is cut off, adjust photoPosition (e.g. "50% 10%" moves the crop up). On phones it shows as a circle.

Résumé button

Drop your PDF into the main folder and set resume: "Mia_Solomon_Resume.pdf",. Leave it "" to hide the button.

Accent color

Change accent: "#2059bd", to any hex color. Some that suit the gray background: #0f766e teal, #7c3aed violet, #c2410c burnt orange, #be185d raspberry.

Links

Fill in your LinkedIn URL under socials. Any social with an empty url: "" is hidden automatically.

7 · Put it online (free, with GitHub Pages)

Your site will live at https://msolomon8.github.io.

  1. On github.com, click New repository. Name it exactly msolomon8.github.io, set it to Public, and create it.
  2. Click uploading an existing file, and drag in everything inside your mia-portfolio folder (index.html, images, videos, résumé). Click Commit changes.
  3. Go to Settings → Pages. Under “Build and deployment”, choose Deploy from a branch, branch main, folder / (root), and Save.
  4. Wait 1–2 minutes and visit https://msolomon8.github.io.

To update later: edit locally, check the preview, then upload the changed files again (Add file → Upload files) or use GitHub Desktop / VS Code's Source Control tab to commit and push. The live site updates in about a minute.

If you already have a repo for this, any repo works too. Turn on Pages in its settings and the address becomes https://msolomon8.github.io/REPO-NAME. Then swap the Notion link on your résumé and LinkedIn for the new one.

8 · If something breaks

The page is blank or stuck → there's almost always a typo in the SITE block. Undo (⌘Z) until it works again, or look for:

  • A missing comma at the end of a line or after a }
  • A missing or extra quote (a straight " inside your text). Use ’ instead.
  • An unmatched [ or {

To find the exact line: in Chrome, right-click the page → Inspect → Console tab. The red error shows a line number in index.html.

A photo shows as a broken icon → the file name in media doesn't exactly match the file in images/ (check spelling, capitals, and .jpg vs .jpeg vs .png).

Video doesn't play → .mov files from iPhone sometimes don't play in Chrome. Export as .mp4 (QuickTime → File → Export As → 1080p) or use YouTube.

Fonts look plain when offline → normal. The fonts load from Google Fonts when you're online.
